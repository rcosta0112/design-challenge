**Status:** Not started. **Phase:** 2.

Every message the user and the AI exchange in the prototype, in order, by screen tag. The screens use this text exactly. The numbers come from the story data in `01-understand/persona.md`.

## Voice

- Plain, short and warm, but not chatty. No exclamation-mark enthusiasm about money.
- Says what it did, and what it's unsure about.
- Never says "I've done X" before the user approves.
- Calls numbers it worked out "estimates".
