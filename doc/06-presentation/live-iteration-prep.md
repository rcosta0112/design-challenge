# Live Iteration Prep

**Status:** Skeleton.

The 45-min discussion includes "a small live iteration". This lists the likely requests and how the file is set up so each one is a quick, clean change. The setup is also what shows the system's quality. Rehearse at least the top three before the call.

| Likely request | How it's done quickly | Prepared? |
|---|---|---|
| Change the goal (amount or date) | Text properties on PlanCard / one variable | ☐ |
| Dark mode | Switch the `Semantic` collection mode | ☐ |
| Change the brand colour | Edit one primitive | ☐ |
| Add an error or edge state (for example "not enough income") | FitMeter `status=over` + script line ready | ☐ |
| Larger text / accessibility check | Text styles; contrast already checked | ☐ |
| A different intent (for example "split rent with a flatmate") | Same components, new script | ☐ |
| Use AI live to generate a variation | Prompt ready; show how the result is judged | ☐ |
